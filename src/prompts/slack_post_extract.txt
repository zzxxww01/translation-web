## 任务
下面是 SemiAnalysis 公司 Slack 里的一个 thread。公司的社媒同事在这里讨论、修改、排期要发到 X（Twitter）上的帖子。
我负责把要发的那篇帖子翻成中文发到中文平台。请从整个 thread 里找出**最终要发的那一篇帖子**的英文原文，以及它要配的图片。

## 一个 thread 只出一篇帖子
- 帖子可能分成好几条消息发：`1/`、`(2/5)`、`*3/*`、`1/4` 这类编号只表示分段。按编号顺序把各段拼成一篇，**去掉编号**，段与段之间空一行。
- 帖子可能被推翻、改过、整套重发：「let me reedit it」「will make changes and resend」之后又贴了一遍，或者同事给了修改意见后作者重发。**每一段都取最新的版本**，旧版本不要。
- 发帖人（通常是负责发帖的同事）有时会贴出最终改过的文案让人「recheck the captions」，这一版就是最新版本。
- 根消息常常只是一行标题加 @用户组（例如「@用户组 AI Racks Are Heavy」「meme」「gta6」），这不是帖子正文，不要放进原文。

## 清理
- 去掉：@同事、@用户组（「@用户组」）、发帖请求和排期用语（「plz post this」「can u post this tmw」「post this ASAP」「QT this」「sch 11/18」），以及讨论、感谢、玩笑等回复。
- Slack 表情码换成常见 emoji（:alert: → 🚨，:fire: → 🔥，:rocket: → 🚀）；认不出的自定义表情直接去掉。
- 链接去掉跟踪参数（`?s=46`、`?a=…&s=20`），其余原样保留，包括结尾的「Look into becoming a subscriber here: 链接」。
- 不改写、不翻译、不润色原文措辞，只做上面的清理。

## 配图（images 里是每条消息带的图片 ID）
- 选**最终版本所在消息**里的图片，按帖子段落顺序排。
- 之后单独补充的图也要（例如「Adding a map to this」「here is the chart」附带的图）。
- 有人说「换了图 / changed image」并重新贴图时，用新图替换旧图。
- 只从输入给出的图片 ID 里选，不要编造 ID。

## 特殊情况
- 只读消息正文，不看链接里的内容。纯转发：只是让人「QT this <链接> with just this image」，没有自己的正文 → source_text 给空字符串，image_ids 给那张图，note 写「这是转发，只需要配图」。
- 整个 thread 都是讨论、提问或数据分析，没有要发的帖子 → has_post 为 false，note 用一句中文概括这个 thread 在聊什么。
- 拿不准用哪一版（例如两段内容都像最终版，或者旧版被否定后新版没有明确确认）→ 选你认为最可能的作为主结果，另外在 candidates 里给出 1–2 个备选（label 用几个字说明区别，例如「第一版」「Oren 改前的版本」）。

## 建议发送时间
- 找同事说这篇什么时候发：「sch 11/18」「post tmw 9am」「can u post this at 10:30 ET」「Monday 8am」这类，**优先看 at_me 为 true（@了我）的消息和它前后几条**；同一篇改过排期时取最新的说法。
- 每条消息的 time_ct 是它发出时的美中时间（星期几也写了）。「tmw / tomorrow / today / Monday」按**说这句话那条消息的 time_ct** 推出具体日期（YYYY-MM-DD）。
- time 用 24 小时制 HH:MM；只说了日期没说几点 → time 给 null。tz 照原文写的时区缩写或地名（ET、PT、CT、UTC、Beijing…），原文没写就给 null，不要自己猜。
- 没提发送时间 → send_time 给 null。

## 输出
只输出 JSON：
{{"has_post": true, "source_text": "清理后的英文原文", "note": "没有要发的帖子或只是转发时写一句中文说明，其余情况给空字符串", "message_ids": [消息编号], "image_ids": ["F…"], "candidates": [{{"label": "……", "source_text": "……", "message_ids": [], "image_ids": []}}], "send_time": {{"text": "原文里说时间的那句（原样）", "message_id": 消息编号, "date": "YYYY-MM-DD", "time": "HH:MM 或 null", "tz": "原文写的时区或 null"}}}}
没有备选时 candidates 给空数组。
