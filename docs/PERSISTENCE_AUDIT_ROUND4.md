# 继续审计：持久化、快照真实性与边界验证

基线：修复分支业务提交 `fd7a5b16af9ed93457a855f09cc3c071b2d260fd`；源码归档提交 `bda16cecf056cf6318bb50f5ab3bd28e1ea31056`。整合 main `6bf3779a443f3e4b3211977d49932524469e99ef` 的全部九个差异文件；不改主分支，不部署，不调用真实付费模型。

## 修复内容

1. **章节保存后标题来源丢失**：原先只保存四个字段，`synthetic` 和 `title_source` 无法往返。现在完整保存 Section 模型，合成导语不会因为重载而丢失“源文没有这个标题”的标记。旧文件已丢失的来源信息不凭空补造。
2. **损坏段落静默消失**：原先逐段解析遇错直接跳过，之后保存会永久遗漏原段落。现在整章校验；损坏 JSON、非法段落、重复/空 ID、目录身份不符、存在但缺失元数据的章节明确报错，禁止以残缺章节继续回写或导出。保存前也校验，避免错误候选覆盖源文、译文或元数据。
3. **新旧时间格式混用导致列表失败**：混合无时区旧时间与有偏移新时间不再直接比较 datetime，改用对应时间戳排序，修复项目列表、译文候选和会话排序；不重新解释已有无时区记录的时区。
4. **未翻译元信息漏过导出检查**：副标题和来源说明需要参与翻译完整性检查；作者署名等原样保留的元信息仍豁免，并保留主分支新增的严格作者署名名单，避免把普通英文正文误当人名。
5. **目录图片复制的符号链接绕过**：单张图片已有路径约束，但整目录复制仍可能跟随链接复制源目录之外的文件。现在拒绝链接目录入口，复制时跳过链接文件和链接子目录，保留正常相邻资源。
6. **术语快照只是 ID 列表**：新会话现在冻结实际术语定义，后续修改/删除词条不改变旧会话的验证基准；同一 ID 的译法、策略或说明变化也能检测。返回深拷贝，读取一批术语不再为每个 ID 重复扫描全词表。旧 ID-only 会话保留兼容读取，但明确警告无法恢复历史定义。
7. **会话并发丢更新与中途写坏**：用跨实例/进程文件锁覆盖完整读改写，加原子替换。进度并发更新不再互相覆盖；模拟磁盘替换失败后，旧记录字节保持不变。校验会话 ID、文件身份、链接与目录边界。
8. **非法重试配置伪装成保存成功**：原子写入的零/负/非整数次数、无效延迟现在在触碰文件前拒绝，不再跳过提交循环后无声删除临时结果。
9. **残缺模型响应被部分接受**：JSON 容错仅保留完整对象前后的正常说明兼容，不将额外闭括号、未闭合代码围栏、逗号残片或多个 JSON 值当作完整审校。标题专用解析可以容忍上游字符串内控制字符，但仍拒绝重复键、非有限数值和截断结构；错误日志不记录原文内容。
10. **极长数字请求头触发 500**：Content-Length 先规范前导零并按数字串比较，不直接把上千位数字转换成整数。超限返回 413，合法前导零不会改变数值；实际流式长度检查继续生效。
11. **主分支改动与 CI 维护**：保留标题控制字符修复、单次格式重试、共享截止时间及新增上游测试；保留 v2 事实约束而不是恢复旧标题示例。浏览器回归加入正式 CI，ESLint 禁止新增警告；临时准备/发布工作流在完成后清理。

## 使用注意
