# 进一步修复：请求生命周期、编辑数据保护与页面安全

基线为修复分支 `b6ac87e`；保留该分支已有的提示词 v2、资源下载防护、规则快照和依赖升级。本轮不合并 main、不部署、不调用真实付费模型，也不声称代码已经没有任何未知问题。

## 已修复的可复现问题

1. **请求线程上下文与排队**：专用 LLM 线程不继承 ContextVar，导致请求级提示词/规则快照和指标丢失。现为每次提交复制上下文；限制运行与排队总数，取消已排队工作不再迟到调用模型。运行中调用占用的名额在实际结束后释放，拒绝无界积压，并单独报告繁忙 503。
2. **超时与取消**：前端超时覆盖完整响应体而非仅等待响应头；外部主动取消不再与超时混淆。Headers/请求凭据/已有 query 参数正确传递。上传支持主动取消、空成功响应及明确的坏 JSON 错误，浏览器自行生成 multipart boundary。
3. **SSE 生命周期**：缺少终结事件的断流不再视为完成，畸形消息明确失败，读取器会关闭。旧项目取消响应不得中止新项目；零进度不再被旧进度覆盖。
4. **编辑竞态**：侧边弹窗和沉浸编辑共用串行操作与本地恢复逻辑。重译/确认返回不能覆盖等待期间新输入；旧项目响应只能更新所属项目。批量操作先登记屏障再等待已有保存；失败不会产生未处理的 tracker Promise。确认旧稿后仍有新输入时不自动跳到下一段。
5. **恢复和人工内容**：本地草稿记录原文/服务端版本；未知或不一致的旧草稿只恢复供核对，不自动覆盖远程。图片清理保护人工、已确认和历史版本。
6. **页面内容安全**：文档表格使用 DOMPurify HTML 消毒，不能执行导入的脚本、事件属性或 javascript 链接。项目静态 HTML/SVG 直接访问使用 sandbox CSP、nosniff、no-store，不修改可信 SPA 静态资源策略。新增 dompurify 锁文件由 npm 解析而非手写。
7. **模型输出完整性**：非空不等于完整；显式 length/MAX_TOKENS 等结束原因被拒绝，不把半截译文、截断 JSON 或安全拒绝视为成功。Gemini REST 保留所有非思考文本块。
8. **时区工具**：修复“12点”变零点、中文半点/分钟、来源时区相对日期、负半小时时差和带偏移 ISO 输入。只接受完整匹配，不吞无效尾缀；未知时区和 DST 不存在/歧义的本地时刻明确拒绝，后者允许用显式偏移消歧。历史 PST/EST 等仍按既有产品约定映射到地理时区并自动 DST。
9. **图片识别与预览**：只识别独立图片，不因正文提及 `.png`、普通链接或 read/write 就跳过翻译。dry_run 正确统计但不写盘，错误统计不扫描普通正文。
10. **一致性检查**：共享词边界/正文判断，避免 AI 命中 said、代码和 URL；保留英文策略、多义词不机械套单一译名。禁止将整段译文替换成一条“建议统一使用…”指令。未执行风格审查显示“未评估”，公开检查范围。仅做轻量一致性诊断，不冒充原文保真评测。
11. **遗漏的旧提示词路径**：确认页重译弹窗的失败兜底仍包含 15–30 字拆句、删连接词规则；现同样使用共享编辑配置，查询按项目隔离。
12. **前端状态**：术语中心查询按项目分组，切作用域的编辑器重置改为事件处理，后台刷新不覆盖正在填写的术语。微信公式结果绑定对应 HTML；懒加载失败明确降级，旧渲染不能替换新内容。消除本轮扫描见到的 Hook 警告，没有关闭规则。更新请求校验，拒绝空确认、重复段落 ID 及伪造 system 历史角色。

## 验证

本地源码验证：后端 1104 passed / 2 skipped，前端 76 passed；TypeScript 与 Vite 生产构建通过；ESLint 使用 `--max-warnings 0` 通过。跳过的是显式要求真实模型服务的两项测试。最终完整仓库数字与浏览器实跑以 PR CI 为准。

新增浏览器 CI：在隔离服务与 Chromium 中运行已有移动端导航、帖子布局、后台任务切页、微信公式测试，以及导入表格脚本防护、侧边重译保留输入、确认期间新稿保护。测试翻译接口采用模拟响应，不消费真实模型额度。失败会保留截图、trace 和服务日志。

依赖安全以当次 npm audit / pip-audit 输出为准；要求审计成功且没有被跳过的依赖，不能以工具错误当作零漏洞。MathJax 第三方 bundle 仍有 eval/体积构建警告，不通过关闭告警掩盖，也不将其混同于已知依赖漏洞。

## 操作与边界

需要同步更新前后端并重启服务。人工草稿版本冲突会显示需要手动核对的提示；自动保存仍不能替代离线备份。复核和容量保护不等于可取消已发出的模型请求。真实翻译质量、完整业务覆盖和生产环境负载尚需实际语料/环境验收；上述回归测试只对已构造场景提供证据。
