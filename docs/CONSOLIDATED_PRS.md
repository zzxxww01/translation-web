## 冲突解决原则与落地

没有整文件选择一边后丢掉另一套能力。以 #3 的运行链路为主线，将 #2 的独有能力接入同一实现；兼容模块委托主实现，不另起一套存储或计数链路。两边的专项回归测试均保留，另增 19 项跨 PR 集成用例。

- **Slack 与 main**：保留中转拆行键名/字符串恢复，同时继续拒绝重复键、非有限数字、截断和多重 JSON。规范化后键名冲突报错，空内容不伪装成功。原 main 的正常恢复用例保留；损坏 JSON 的单测从返回空对象调整为显式抛错，业务接口仍报告明确失败。
- **模型策略**：顶层 `model_scope/model_profile` 与旧 `efficiency.model_scope/profile` 均可用。同一请求出现相互矛盾的值直接拒绝。物理模型相同但通道别名不同，不复用错误路由。术语预检保留实际阶段模型身份，并复用已经配置的 facade。
- **参数统一**：`src.config.efficiency.EfficiencyOptions` 为唯一模型；`src.core.efficiency` 仅兼容导入。`stage_resume/max_stage_seconds/max_run_seconds` 兼容映射到 `resume_stages/stage_timeout_seconds/run_timeout_seconds`；两种拼法冲突报错。时间支持有限的正数，含旧接口的小数秒；非法布尔值和非有限数仍拒绝。
- **检查点统一**：运行链路使用 `WorkCheckpointStore`。旧 `StageCheckpoints` 委托同一存储，保留命名空间、编解码和显式重译行为。相同键的计算通过跨实例/进程文件锁去重；等待遵守取消/截止时间。成功结果才写入，故障和未完成审校不缓存为通过。
- **预算单位明确**：生产链路按实际传输 admission 计数，重试计入；兼容调用明确采用逻辑生成单位。共享同一父子原子预留和截止时间实现，不把两种单位混计。可选估算 token 预算按调用预留，不是账单金额或精确计费 token。最后一次允许的响应仍能保存。
- **请求窗口**：保留 #3 的物理模型输入/输出/共享上下文检查和 #2 的可选操作方请求上限。显式输出上限必须参与检查。四步法及普通章节模式均能按完整 prompt 拆批、保留有效部分和阶段结果；单段/整章审校无法容纳时明确保留待处理，不截断原文。
- **质量状态**：兼容两种历史质量证明，统一校验源文、译文、策略和格式。写入新结果同时维护状态和证明；改动后旧通过标记无效。失败明确区分 review/revision/verification pending；人工确认及未确认人工修改不自动重写。
- **本地读取**：保留有界解析缓存、深拷贝和纳秒文件身份；读取期间发生替换会重新读取，连续变化明确报错。损坏新文件不会回退为旧缓存成功。
- **紧凑审校**：默认仍关闭，保留完整检查和最小源译证据；旧 reason 字段兼容规范化为 description。两者同时存在且不同会报错，不静默覆盖。

## 统一默认值与兼容边界

| 参数 | 默认值 |
| --- | --- |
| resume_stages | true |
| prescan_concurrency | 1，保守保留串行，可显式设 1–8 |
| compact_review | false |
| model_scope / model_profile | all / default |
| stage_timeout_seconds / max_stage_calls | 1800 秒 / 64 次实际传输 |
| run_timeout_seconds / max_run_calls | 14400 秒 / 2000 次实际传输 |
| max_run_estimated_tokens | 不默认设置 |
| max_request_input_tokens / max_context_tokens | 不默认编造窗口，可显式设置 |

前端同时支持旧的扁平效率参数和新的顶层模型策略加 nested efficiency；不会跨请求复用上次参数，也不会改变重译范围。混杂且不明确的结构拒绝提交。

检查点保存于项目的 `artifacts/work-checkpoints-v1`：结果单条至多 8 MiB，每项目至多 1024 条 JSON。锁文件为避免替换活跃锁的 inode 而保留；其清理只应在任务安全停止后进行。旧 `stage-cache-v1` 不会未经校验迁移为当前通过结果；失去缓存只导致重新计算，不删除正式译文。

前序审计文档保留作历史记录；其中默认并发、模块位置、计量单位等存在差异时，以本文及当前代码为准。
